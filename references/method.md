# REA 五层还原法

逆向工程不是"看懂"，是**逐层把不确定性压缩掉**。每一层都为下一层提供立足点，
跳层必然产生幻觉。五层的顺序不可颠倒，但允许迭代回头（L4 的假设常需要回到 L3 补证）。

---

## L1 · 是什么（身份与形态）

**目标**：确定目标的物理形态、来源、可信度与授权状态。

**取证动作**
- 文件：`python3 scripts/peek.py <路径>` —— 魔数、熵值、字符串、结构探测。
- 目录：`python3 scripts/peek.py <目录> --depth 3` —— 类型分布、入口点、高熵文件。
- 非文件目标（一个功能、一条流程、一个界面）：先把它**物化**为可观测对象
  （抓包、截图、日志、可运行的入口），否则后续全部是空谈。

**判读要点**
| 观测 | 含义 |
|---|---|
| 熵 ≥ 7.5 | 加密或强压缩，当前不可读 |
| 熵 6.5–7.5 | 压缩数据或未压缩二进制 |
| 熵 < 4.5 | 文本/结构化数据 |
| 魔数未命中 + 满熵 | 裸密文或私有格式，边界止于此处 |

**常见错误**：在没有确定形态前就开始猜内容。先形态，后语义。

---

## L2 · 由什么组成（结构与边界）

**目标**：把目标分解为有限个**可命名**部件，并画出它们的关系。

**取证动作**
1. **锚点优先**：先找能一次定结构的锚点——`package.json` / `go.mod` / 魔数 / 文件头 / 表头 /
   目录约定。锚点的价值远高于逐字节猜。
2. **分层下钻**：外壳 → 容器 → 内容 → 内容的内容。每层只回答一层的问题。
3. **命名**：给部件可引用的名字（`auth_middleware` 而非"模块 A"）。
4. **关系**：只画三种——包含、依赖、数据流/调用。

**判读要点**：部件边界看不清时，用"能否单独替换/删除"来检验。
能单独替换的才是真部件，否则只是一个区域。

**常见错误**：用"通常这类项目会有 X"补全没观测到的部件。没看到就是没看到，进未知清单。

---

## L3 · 怎么运作（机制与行为）

**目标**：钉死输入 → 处理 → 输出 → 副作用的完整链路，以及每个字段的语义。

**取证动作**
1. **最小可复现输入**：找出能触发行为的最小输入，固定随机源，使行为可重复。
2. **基线 + 单点扰动**：先记录一次不改任何东西的观测，再**一次只改一个变量**。
   这是定位因果的唯一可靠方法。
3. **多样本对齐**（格式类）：≥3 个同类样本横排对比，看哪些字节恒定、哪些随内容变。
4. **最小改动实验**（字段语义）：改输入的一个属性，看报文中哪些字节变化。
5. **边界值验证**（类型假设）：用 0 / 1 / 255 / 256 / 65535 验证类型假设，不凭"看起来像"。

**输出物**：字段映射表 —— `offset → 长度 → 字段名 → 类型 → 语义 → 证据等级`。

**常见错误**
- 单样本逆向字段（必然错）。
- 反编译结果直接当事实（应作线索，需汇编级或行为级佐证）。
- 给函数起"看起来合理"的名字（无法确定就保留 `sub_XXXX`）。

---

## L4 · 为什么这样（约束与意图）

**目标**：区分"客观约束"与"主观动机"，只把有证据支撑的部分写进结论。

**取证动作**
1. **约束优先**：不问"作者想要什么"，找**可观测的约束**——性能预算、兼容包袱、
   平台限制、合规要求、历史遗留。观测点：注释与 TODO、配置项默认值、
   兼容分支（`if version <`）、降级路径、错误处理粒度。
2. **取舍必须有代价**：真取舍一定能指出"放弃了什么"。只说好处不说代价 = 事后合理化，降为 E3。
3. **反例检验**：为你的解释找一个它预测的反例，去验证。预测失败就推翻，不要修补故事。
4. **时间维度**：查历史版本，看设计如何演变。演进路径暴露真实动机，最终态总是"看起来理所当然"。
5. **同源对照**：同期其他产物是否同模式？可区分"刻意设计"与"惯性"。

**输出物**：两栏，**不得混写**——`有据意图(E0/E1)` 与 `可证伪假设(E2/E3)`。

---

## L5 · 怎么复刻（规格与验收）

**目标**：产出能让第三方在不接触原目标的情况下实现出来、并证明一致的规格。

**取证动作**
1. **先钉保真度**：`behavioral_parity`（同输入输出同副作用）与
   `functional_equivalent`（外部行为一致、实现可不同）的工作量差一个量级，
   开始前必须与用户确认。
2. **接口契约优先**：签名、参数类型与取值范围、返回值、错误码、异常行为、
   时序与并发语义、版本兼容承诺。
3. **数据结构固化**：类型定义 + 不变式 + 边界条件。
4. **伪代码**：核心算法给伪代码，复杂度对齐，关键常量标注来源证据。
5. **验收测试**：正常路径 / 边界（空、0、最大、超界）/ 错误路径 / **差分测试**（同输入比对原目标）。
6. **未知清单**：未钉死的点列表，标注影响面与获取方式。

**常见错误**：为了规格"完整"而编造接口细节。缺什么就写在未知清单里。

---

## 迭代与回头

五层是**主干不是瀑布**。典型回流路径：
- L4 提出假设 → 回 L3 设计实验验证 → 修正 L3 结论 → 更新 L4
- L5 发现契约钉不死 → 回 L3 补观测 → 或明确写入 `blocking_unknowns`

每次回头都要更新证据等级，**不要**因为"之前写过"就保留旧结论。
